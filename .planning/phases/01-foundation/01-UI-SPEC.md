## Spacing Scale

Declared values (must be multiples of 4). MUI v6 default spacing unit is 8px; the Insights
platform uses 8px-base spacing consistently.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, chip padding, inline padding within dense controls |
| sm | 8px | Between label and input, between icon and text, compact row padding |
| md | 16px | Default element spacing, card internal padding, date picker side padding |
| lg | 24px | Section padding, header vertical padding, between header and content |
| xl | 32px | Layout gaps, page section breaks |
| 2xl | 48px | Major section vertical margins |
| 3xl | 64px | Page-level top/bottom padding (reserved for future phases) |

Exceptions:
- Date range picker input height: 36px (MUI sizeSmall — not on the 8pt scale but matches platform convention observed in AircraftManagement ButtonWrap)
- MUI IconButton touch target: 40px minimum (MUI default, overridden to 0px padding in Theme.tsx — outer click area satisfies WCAG 2.5.5 via wrapping element)

All type is rendered via MUI Typography component using the theme defined in `theme/Theme.tsx`.
Sizes below are the rendered pixel values after MUI `responsiveFontSizes()` processing at 1440px viewport.

| Role | Size | Weight | Line Height | Font | MUI Variant | Usage |
|------|------|--------|-------------|------|-------------|-------|
| Body | 16px | 400 (normal) | 1.5 | Source Sans Pro | body1 | General UI text, date range labels, metadata |
| Label | 16px | 600 (semibold) | 1.0 | Source Sans Pro | label (custom) | Form labels, field names, section headers in controls |
| Page Title | 20px | 600 (semibold) | 1.2 | Uni Neue | h6 | Tail ID display in page header (e.g. "N12345") |

**Two weights in use: 400 (normal) and 600 (semibold).**

All colors imported from `src/theme/colors.ts`. No hardcoded hex values in components.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant surface (60%) | SURFACE_GREY[100] | #F2F5F8 | Page background (matches theme `background.default`) |
| Secondary surface (30%) | WHITE (#FFF) / SURFACE_GREY[50] | #FFFFFF / #FDFEFF | Page header card, date picker popover, control panel |
| Accent (10%) | PRIMARY_PURPLE | #724AE8 | Date range picker active selection, primary CTA button fill |

| Secondary text | theme text.secondary | #202E39B2 (70%) | Placeholder text, helper text, disabled labels |

- No left navigation sidebar in Tail History — this is a focused single-page view, not a multi-page app nav

## Interaction Contract

### Date Range Picker

| State | Visual |
|-------|--------|
| Default (on page load) | Shows last 14 days — start: today minus 14 days, end: today |
| Open (calendar visible) | MUI DateRangePicker popover anchored below the picker input |
| Date selected | Range fill in PRIMARY_PURPLE tint; start and end dates in solid PRIMARY_PURPLE |
| Invalid range (end before start) | Inline error below picker: "End date must be after start date" in ERROR_RED, caption size |
| Applied | Picker closes; React Query cache invalidated; all queries refetch |
| Loading (after apply) | No visual change to header; per-chart loading states fire in Phase 2+ |

### Tail ID Display

| State | Visual |
|-------|--------|
| Loaded | Tail ID (e.g. "N12345") in Uni Neue 20px/600, PRIMARY_GREY (#32424E) |
| Not found / unknown | "—" em-dash placeholder in same style, secondary text color |

Tail ID is read from the URL parameter (e.g. `/tail-history/:tailId`). If the param is absent,
redirect to a 404 or the platform's default route. (Routing convention: URL param, not query string,
because tail ID is a primary resource identifier — matches insights-manager `useUrlParams.ts` pattern.)

## Highcharts Global Theme Contract

Highcharts global defaults are set in Phase 1 before any chart renders. These are not visual
choices — they are correctness requirements that cannot be retrofitted later.

```typescript
// Set once in src/main.tsx or src/App.tsx, before any <Chart> renders
Highcharts.setOptions({
  time: {useUTC: true},
  plotOptions: {
    series: {turboThreshold: 0}
  },
  chart: {
    style: {
      fontFamily: 'Source Sans Pro, sans-serif'
    },
    backgroundColor: 'transparent'
  },
  title: {style: {fontFamily: 'Uni Neue, sans-serif', fontWeight: '600'}},
  xAxis: {
    gridLineColor: '#DEE4E8',   // SURFACE_GREY[150]
    lineColor: '#DEE4E8',
    tickColor: '#DEE4E8',
    labels: {style: {color: '#465967', fontSize: '12px'}} // SURFACE_GREY[600]
  },
  yAxis: {
    gridLineColor: '#DEE4E8',
    labels: {style: {color: '#465967', fontSize: '12px'}}
  }
});
```

These values are the only place hex values are permitted outside `colors.ts` — Highcharts setOptions
does not accept CSS custom properties. Comment each value with its `colors.ts` constant name so
future maintainers can cross-reference.
