**Replace the separate event callout with a unified tooltip:**

Currently, event markers in ChartStrip.tsx use a completely separate rendering mechanism (`showEventCallout` / `hideEventCallout`) that creates an SVG renderer label on the chart. This produces a SECOND tooltip that competes with the Highcharts tooltip. The user wants ONE tooltip that shows both series data AND event info.

1. **Remove** the `showEventCallout` and `hideEventCallout` functions entirely.
2. **Remove** all `events: { mouseover, mouseout }` handlers from the `plotLines` and `plotBands` configurations (the event marker xAxis config). Keep the plotLines and plotBands themselves for visual rendering (the dashed vertical lines and colored bands should remain).
3. **Add a custom `tooltip.formatter`** that:
   - Receives the hovered point(s) via `this.points` (since `shared: true`)
   - Checks the current `x` timestamp against the `eventMarkers` array to find any events whose `[timestamp, endTimestamp]` range includes the hovered x value
   - Builds a single HTML tooltip string with:

   **Format specification:**
   ```
   ┌──────────────────────────────────┐
   │ May 10, 2026 14:30 UTC          │  <-- timestamp, left-aligned, 8px bottom margin
   │                                  │
   │ Series1        ● 42.5 Mbps      │  <-- label left, color dot + value right
   │ Series2        ● 88.2%          │  <-- label left, color dot + value right
   │                                  │
   │ ── Events ──────────────────     │  <-- divider (only if events present)
   │ 🔴 Signal Lost                  │  <-- event label in event color
   │   Network transition detected   │  <-- event description (if present)
   └──────────────────────────────────┘
   ```

   Implementation of the formatter function:

   ```typescript
   tooltip: {
     split: false,
     shared: true,
     useHTML: true,
     formatter: function (this: Highcharts.TooltipFormatterContextObject): string {
       const x = this.x as number;
       // Format timestamp: "May 10, 2026 14:30 UTC"
       const dateStr = Highcharts.dateFormat('%b %e, %Y %H:%M UTC', x);
       
       // Build table for series data
       let html = `<div style="font-size:12px;line-height:1.5">`;
       html += `<div style="font-weight:600;margin-bottom:8px">${dateStr}</div>`;
       html += `<table style="border-collapse:collapse;width:100%">`;
       
       const points = this.points || [this];
       points.forEach((pt: any) => {
         const color = pt.series?.color || pt.color || '#666';
         const name = pt.series?.name || '';
         const val = pt.y != null ? Highcharts.numberFormat(pt.y, 2) : '—';
         const unit = pt.series?.options?.tooltip?.valueSuffix || '';
         html += `<tr>`;
         html += `<td style="text-align:left;padding-right:16px">${name}</td>`;
         html += `<td style="text-align:right"><span style="color:${color}">●</span> ${val}${unit}</td>`;
         html += `</tr>`;
       });
       html += `</table>`;
       
       // Find matching events
       // eventMarkers is captured via closure (see below)
       if (currentEventMarkers && currentEventMarkers.length > 0) {
         const matchingEvents = currentEventMarkers.filter(evt => {
           const end = evt.endTimestamp ?? evt.timestamp;
           return x >= evt.timestamp && x <= end;
         });
         if (matchingEvents.length > 0) {
           html += `<div style="border-top:1px solid rgba(255,255,255,0.3);margin:6px 0;padding-top:6px;font-weight:600;font-size:11px;opacity:0.7">Events</div>`;
           matchingEvents.forEach(evt => {
             html += `<div style="color:${evt.color};font-weight:600;font-size:12px">${evt.label}</div>`;
             if (evt.description) {
               html += `<div style="font-size:11px;opacity:0.85;margin-left:4px">${evt.description}</div>`;
             }
           });
         }
       }
       
       html += `</div>`;
       return html;
     }
   }
   ```

   **Closure approach for eventMarkers:** The `eventMarkers` prop must be accessible inside the formatter. Since the Highcharts options object is built in the component body (not in a hook), the `eventMarkers` variable from the component scope is naturally in the formatter's closure. However, to make this clear, store `eventMarkers` in a variable `currentEventMarkers` at the top of the options construction, or simply reference the `eventMarkers` parameter directly. Since the component re-renders when `eventMarkers` changes, and the `chartOptions` object is rebuilt each render, the closure will always have the current value.

4. **Keep `tooltip.split: false` and `tooltip.shared: true`** — these are already set.
5. **Add `tooltip.useHTML: true`** — needed for HTML formatting.
6. **Add `tooltip.backgroundColor: 'rgba(20,20,20,0.88)'`** and `tooltip.style: { color: '#fff' }` to match the dark tooltip style that the old event callout used.
7. **Add `tooltip.borderColor: 'transparent'`** and `tooltip.borderRadius: 4` and `tooltip.padding: 8`.

**Important:** The plotLines and plotBands for event markers should REMAIN as visual indicators on the chart. Only remove their `events` (mouseover/mouseout) handlers since the tooltip now handles event display.
