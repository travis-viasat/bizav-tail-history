- `Switch` -- `onText`, `offText`, `textPosition`, `disabled`, `readOnly`; self-contained label (replaces MUI Switch + FormControlLabel)

- `TextField` -- `label`, `placeholder`, `disabled`, `fluid`, `contentBefore`, `contentAfter`, `error`, `helperText`
- `Text` -- `variant` (heading-2xl...6xl, body-md, detail, label), `bold`, `color`, `as`
- `Checkbox` -- Beam Checkbox component
- `Card` -- sub-components: `Card.Header`, `Card.Body`, `Card.Footer.Actions`; props: `density`, `type` (clickable|selectable), `onClick`
- `SegmentedControl` -- already swapped in ChartTypePicker

**MUI components to KEEP (no Beam equivalent):**
- `Drawer`, `Skeleton`, `List`, `ListItem`, `ListItemButton`, `ListItemIcon`, `ListItemText`, `ListSubheader`, `Box`, `StyledEngineProvider`, `ThemeProvider`, `CssBaseline`

**MUI icons:** Keep `@mui/icons-material` imports. Pass MUI icon elements to Beam `iconBefore`/`iconAfter` props.

**Typography mapping (MUI variant to Beam variant):**
- `variant="h4"` --> `variant="heading-xl"` with `bold`
- `variant="h5"` --> `variant="heading-lg"`
- `variant="h6"` --> `variant="heading-md"`
- `variant="subtitle1"` --> `variant="label"` with `bold`
- `variant="subtitle2"` --> `variant="label"`
- `variant="body1"` --> `variant="body-md"`
- `variant="body2"` --> `variant="body-md"`
- `variant="caption"` --> `variant="detail"`

**Beam Text color values:** primary, secondary, positive, warning, negative, infoPrimary, infoSecondary, selected, disabled, inversePrimary, inverseSecondary

**MUI Button to Beam Button mapping:**
- `variant="contained"` --> `appearance="accent"` `kind="filled"`
- `variant="outlined"` --> `appearance="neutral"` `kind="outlined"`
- `variant="text"` --> `appearance="neutral"` `kind="ghost"`
- `startIcon={X}` --> `iconBefore={X}`
- `endIcon={X}` --> `iconAfter={X}`
- `size="small"` --> `size="sm"`
- MUI `IconButton` --> Beam `Button` with `iconOnly` boolean prop and pass the icon as `children` or `iconBefore`

**Important constraints:**
- Keep MUI `styled()` calls -- only swap component imports, not the styling system
- Keep the Viasat copyright header in every file
- Do NOT touch test files
- Where Beam `Text` is used inside an MUI `styled()` wrapper (e.g. `const SelectionCount = styled(Typography)(...)`), change to `styled(Text)` from beam-react. If the styled wrapper only set fontSize or basic CSS that the Beam variant handles, remove the styled wrapper and use Beam props directly.
- Beam `Chip` uses `dismissible` + `onDismiss` instead of MUI's `onDelete`. Beam Chip uses `children` for label text, not a `label` prop.
- Beam `Switch` is self-contained with label text built in -- replaces MUI `Switch` + `FormControlLabel` combo. Use `onText`/`offText` or just children for label.
- Beam `Slider` uses `range={[min, max]}` instead of separate `min`/`max` props.
